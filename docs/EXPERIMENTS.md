# Серии экспериментов

В версии **0.6.0** появился Experiment Lab: отдельное окно, в котором можно изучать, как один параметр влияет на поведение клеточного автомата или экосистемы. Для опытов создаются **независимые копии миров**. Текущую симуляцию они не изменяют.

## Как провести опыт

1. Откройте **Анализ → Серии экспериментов** или нажмите `Ctrl+E` в главном окне.
2. Выберите один параметр, его начальное и конечное значения, число вариантов и повторов.
3. Задайте число поколений, частоту записи показателей и начальный seed.
4. Выберите «Новый мир» или, для параметров среды экосистемы, «Копия текущего».
5. Нажмите «Запустить серию». Результаты обновляются по мере завершения отдельных запусков; можно приостановить или отменить работу.
6. Измените показатель сравнения, изучите график и выгрузите итоги CSV, временные ряды CSV, полные результаты JSON или Markdown-отчёт.

Во время опыта редактор главного мира остаётся доступен. Изменения, сделанные в нём **после** запуска серии, на уже созданную серию не влияют. Новая серия создаёт новые миры. Перезапуск из того же плана с тем же seed должен давать те же результаты при той же версии модели.

## Какие параметры можно изменять

| Режим | Параметр | Диапазон | Начальные условия |
|---|---|---:|---|
| Конвей | Доля живых клеток | 0–1 | Новый мир |
| Экосистема | Доля растений | 0–1 | Новый мир |
| Экосистема | Доля травоядных | 0–1 | Новый мир |
| Экосистема | Доля хищников | 0–1 | Новый мир |
| Экосистема | Осадки | 0–1 | Новый мир / копия |
| Экосистема | Температурный фон | 0–1 | Новый мир / копия |
| Экосистема | Перенос влаги | 0–0.5 | Новый мир / копия |
| Экосистема | Перенос минералов | 0–0.3 | Новый мир / копия |
| Экосистема | Длина сезона | 30–720 поколений | Новый мир / копия |

Параметры климата автоматически активируют расширенную модель среды для экспериментальных миров. Остальные экологические настройки для новой серии берутся из текущего мира в момент её запуска. При создании новых миров используется фиксированная базовая смесь видов: 17% растений, 1.8% травоядных, 0.3% хищников, кроме варьируемой доли. Если суммарная плотность превосходит 100%, план отклоняется.

Для классической модели используется правило и тип границ, выбранные в главном окне. Эксперимент с «копией текущего» позволяет изменять только свойства среды: изменение стартовой плотности потребовало бы произвольного удаления или добавления уже существующих организмов.

## Как обеспечивается воспроизводимость

- Для повтора номер 1 применяется базовый seed, для второго — `seed + 1` и т. д.
- **Во всех вариантах одного повтора исходный seed одинаковый.** Так проще сравнивать результаты при одинаковых стартовых условиях. При этом сами траектории могут расходиться: симуляции с разными параметрами делают разное количество вызовов генератора случайных чисел.
- Для «Нового мира» начальное состояние формируется заново с этим seed. Для «Копии текущего» массивы и настройки копируются в память, а случайный генератор получает seed соответствующего повтора.
- Параметр изменяется только в экспериментальном мире. Оригинал не перезаписывается, в нём не меняется RNG, и его сохранение не затрагивается.
- Случайная модель упрощена и не заменяет статистическую оценку на реальных биологических данных.

## Что означают числа

**Итоговая таблица** показывает среднее значение выбранного показателя по завершённым повторам, `N` (число повторов), `σ` (выборочное стандартное отклонение) и `Δ к базе` — среднюю разницу с первым вариантом **при том же номере повтора**. При одном повторе стандартное отклонение не показывается. Разница сама по себе **не означает доказанный эффект**: для этого нужны достаточные повторы, интервал неопределённости и проверка допущений.

**График** отображает средние показатели по завершённым и идущим повторам на записанных контрольных шагах. Он не показывает неопределённость. Чтобы увидеть все траектории отдельно, выгрузите CSV временных рядов. Показатель записывается при старте, затем каждые `N` шагов, и всегда при завершении опыта.

**Досрочная остановка** применяется только в экосистеме, если исчез один из видов животных, присутствовавших в начале запуска. При остановке в `steps` сохраняется реальная длина опыта. Незавершённые поколения не моделируются; индикатор выполнения учитывает пропущенную часть, чтобы переходить к следующему варианту.

## Форматы экспорта

- `summary.csv` — одна строка на завершённый запуск, seed, параметр, максимальная/средняя/конечная численность, число рождений и смертей, виды и момент исчезновения животных.
- `series.csv` — записи по поколениям, отдельные ряды для повторов, численность видов, рождения и смерти **за интервал с предыдущего замера**, доступные почвенные и энергетические показатели. Отсутствующие показатели оставляются пустыми.
- `.json` — весь план (включая настройки среды), итоги, временные ряды и состояние завершённости. Формат `life.experiment_suite`, версия 1.
- `.md` — читаемый протокол плана и сравнительная таблица, пригодный для хранения в журнале проекта.

CSV записывается в UTF-8 с BOM для Excel. Экспорт не запускает новые поколения и не изменяет ни один мир.

## Ограничения

Диапазон включает от 2 до 12 вариантов, число повторов — от 1 до 12, длина опыта — от 1 до 1500 поколений. Общий план не может превышать **16 000 запланированных шагов**. Новый экспериментальный мир ограничен размерами **250×180 клеток**, чтобы случайно не начать чрезмерно тяжёлую серию. При работе с копией мира больше этого размера один шаг всё равно может быть медленным; интерфейс между шагами остаётся отзывчивым, но сам шаг выполняется в основном потоке.

Серии существуют в памяти окна до закрытия: для сохранения результатов выполните экспорт. Экспериментальный JSON — **отчёт**, а не файл сохранения `.lifelab`. В версии 0.6.0 пока нет импорта и визуального сопоставления нескольких JSON-отчётов. Это отдельная будущая задача.
