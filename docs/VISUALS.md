# Визуальная система Life

В v0.8.0 я обновил визуальную часть без изменения правил мира и без изменения формата сохранения. Оформление хранится локально, чтобы эксперименты можно было обменивать между пользователями, не привязывая данные к цветовой схеме.

## Темы интерфейса

Восемь тёмных схем, все на чёрной/графитовой основе: «Графит / циан», «Оникс / лайм», «Сталь / янтарь», «Полночь / фиолет», «Обсидиан / лёд», «Уголь / серебро», «Тёмный нефрит», «Тёмная медь». Каждая задаёт поверхности, рамки, текст, вторичный текст, акцент и предупреждения. Изменение темы пересоздаёт Tk-виджеты, но не мир.

## Палитры и виды клеток

Доступны 10 палитр поля. В v0.8.0 добавлены «Северное сияние», «Карбон» и «Сигнал». Цветовая схема не задаёт биологические параметры: каждому типу клеток соответствует постоянный индекс 1–3 независимо от выбранных цветов.

Шесть видов клеток:

- **Свечение** — мягкий свет вокруг заполненной клетки.
- **Мозаика** — отдельные цветные плитки.
- **Схема** — строгая пиксельная сетка.
- **Неон** — подсвеченное ядро и несколько световых колец.
- **Контуры** — тонкая геометрия вместо полной заливки.
- **Созвездие** — компактный маркер с перекрестием при увеличении.

На малых масштабах стили упрощаются: оформление не должно делать отдалённые большие карты нечитаемыми и чрезмерно дорогими для отрисовки. Неоновые спрайты кэшируются по масштабу, типу клетки и палитре; для очень плотных миров при крупном масштабе всё же предпочтительнее «Схема».

## Рабочее пространство

Кнопки «Параметры» и «Исследование» независимо управляют левым и правым столбцами. F6/F7 выполняют те же действия. На ширине менее 1320 px при раскрытии одной панели другая автоматически скрывается. F10 убирает обе панели и по повторному нажатию возвращает предыдущий набор; F11 включает полный экран.

Над картой находится полоса состава популяции. Для классической «Жизни» она одноцветная; для экосистемы цветные сегменты показывают долю каждого вида среди **живых**, а не процент от всей площади. При отсутствии клеток остаётся фоновая полоса.

Переключатель «ШКАЛА» включает отметки координат X/Y на краях поля. Деления адаптируются к масштабу; подписи показываются только в видимой части карты.

## Графики

История численности показывает последние 120 записей, а средние значения генов — отдельные линии травоядных и хищников. При отсутствии вида линия прерывается. Заливка под первым рядом переключается отдельно; при наведении появляется подпись поколения и численности.

Шкала Y графика численности начинается от нуля; верхняя граница автоматически подбирается по данным. Это удобная оперативная панель, а не статистический вывод о закономерностях. Для сопоставимых экспериментов используйте табличные результаты и экспорт CSV/JSON.

## Настройки

Файл `%APPDATA%/Life/preferences.json` (Windows) или `~/.config/Life/preferences.json` (Linux) сохраняет выбор темы, палитры, стиля, сетки, следов, скорости, анимаций, координатной шкалы и заливки графика. Восстановление старых настроек поддержано. Файлы `.lifelab` остаются в формате 5.

## Ограничения

Тёмный нативный заголовок Windows запрашивается через DWM. Для разных сборок Windows и системных тем он может выглядеть по-разному; Linux использует заголовок оконного менеджера. Не все компоненты Tkinter поддерживают аппаратную анимацию, поэтому эффекты интерфейса ограничены короткими переходами цветов.
