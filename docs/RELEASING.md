# Выпуск новой версии

Перед выпуском меняю номер версии в `life_lab/__init__.py`, дописываю изменения в `CHANGELOG.md` и прогоняю проверки:

```bash
python -m unittest discover -s tests -v
```

После этого фиксирую изменения в `main` и ставлю аннотированный тег на проверенном коммите:

```bash
git tag -a v0.3.0 -m "Life v0.3.0"
git push origin v0.3.0
```

Тег запускает `.github/workflows/release.yml`. Workflow собирает ZIP с исходниками выбранного коммита и публикует GitHub Release. Описание берётся из раздела соответствующей версии в `CHANGELOG.md`. Если раздел отсутствует, используются стандартные заметки GitHub.

Теги `v0.1.0` и `v0.2.0` уже опубликованы; их исходники доступны в разделе Releases. Новая версия не должна перезаписывать существующий тег.
