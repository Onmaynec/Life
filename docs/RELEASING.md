# Выпуск новой версии

Перед выпуском меняю номер версии в `life_lab/__init__.py`, дописываю изменения в `CHANGELOG.md` и запускаю тесты:

```bash
python -m unittest discover -s tests -v
```

После коммита в `main` проверка запускается в GitHub Actions. Если изменился файл с номером версии, отдельный workflow ещё раз выполняет тесты, создаёт тег `vX.Y.Z` на проверенном коммите и публикует ZIP с исходниками в GitHub Releases.

Тег не перезаписывается: если он уже существует и указывает на другой коммит, workflow завершится с ошибкой. Когда релиз уже существует, повторная публикация не выполняется.

При ручной публикации тега `vX.Y.Z` workflow также проверяет, что тег совпадает с номером версии в исходниках. Описание выпуска берётся из раздела соответствующей версии в `CHANGELOG.md`.
