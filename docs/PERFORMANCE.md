# Производительность симуляции

Проверка на одном компьютере, Python 3.13, фиксированные seed `119`, плотность `0.15`, 12 шагов на повтор, семь повторов. Зависит от нагрузки ОС, поэтому результаты служат точкой сравнения, а не гарантированным ускорением на любом устройстве.

| Размер поля | v0.8.0, мс/шаг | v0.8.1, мс/шаг | SHA-256 состояния (16 символов) |
| --- | ---: | ---: | --- |
| 160×100 | 4.82–5.08 | 4.10–4.32 | `f493e72b6aa68549` |
| 300×180 | 15.02–16.29 | 13.31–13.41 | `f510a505bcdb6126` |

Приведены повторные серии замеров. Для контролируемого сравнения используйте одну машину без параллельной фоновой нагрузки, одинаковую версию Python и одинаковые seed. Выполнить:

```bash
python tools/benchmark.py
```

В горячем пути сокращена стоимость построения соседей; порядок обхода и число обращений к RNG сохранены. Кэшированы неизменяемые смещения видимости радиуса 1–3; ограничение генов больше не вызывает NumPy для одиночного числа. Проверено совпадение массивов клеток, энергии и ID животных после одинакового числа поколений.

Визуальные тяжёлые измерения не выполняются при каждом шаге. Детализация 3D регулируется независимо от истинного разрешения симуляции. Это не ускорение самой модели и не влияет на её результат.

## Пространственные слои — v0.9.0

Ранее каждый вызов `spatial_field` строил сразу все доступные двумерные поля, включая матрицу соседей и глубины родословной, а затем выполнял Python-цикл по каждому блоку изображения. Теперь выбирается единственное запрошенное поле и выполняется векторное агрегирование NumPy. Для среднего используются истинные размеры краевых блоков.

На одном локальном запуске Python 3.13, NumPy и мире 300×180, seed 11, плотность 0.2, `max_side=50`, медиана 20 измерений:

| Слой | До, мс | После, мс | Снижение времени |
| --- | ---: | ---: | ---: |
| Влага | 12.06 | 0.15 | ~80× |
| Плотность | 12.30 | 0.16 | ~77× |
| Глубина родословной | 11.96 | 1.42 | ~8× |

Это **только время подготовки матрицы для отображения**, а не частота кадров, скорость симуляции или скорость построения всей 3D-сцены. Пользовательские компьютеры дадут другие результаты. Повторяемый текущий бенчмарк:

```bash
python tools/benchmark_spatial.py --repeats 30
```

Тесты сравнивают сумму, максимум и среднее с независимым эталонным расчётом для полных и неполных блоков. Правила симуляции, RNG и файл мира не изменились.
