# Дорожная карта Life

Последняя версия: **v1.0.1 (Hot Bug Fix)**. Этот документ отделяет внедрённые функции от не выполненных обещаний. Даты последующих версий не назначены.

## Выполнено

| Период | Основные возможности |
| --- | --- |
| v0.1–v0.3 | Классический клеточный автомат, экосистема, наследуемые параметры, настройка мира по seed, сохранения, статистика |
| v0.4–v0.5 | Новый тёмный интерфейс, карта и мини-карта, 2D/3D показатели, расширенная экология, структуры и инструменты наблюдения |
| v0.6–v0.7 | Серии параметрических экспериментов, экспорт, родословные с постоянными ID и сравнением генетики |
| v0.8.0–v0.8.2 | Палитры и оформление, адаптивные панели, сравнение архивов, ускорение экосистемы, контрольные точки и автосохранение |
| v0.9.0 | Лента событий, ускоренная пространственная аналитика, измерения производительности |
| v1.0.0 | **Scenario Studio** с парными мирами и расписанием воздействий, проверяемый ZIP-архив опыта, защита загрузки NPZ, DPI-пороговые панели, упакованные UI/engine проверки Windows |
| **v1.0.1** | Исправления модели и аналитики, строгая проверка сохранений, точный экспорт частичных сценариев, вариантное сравнение архивов, безопасная публикация Windows asset, выделение редакторской истории и 3D-модуля |

Полное описание каждой версии — [CHANGELOG.md](../CHANGELOG.md). Архитектура — [ARCHITECTURE.md](ARCHITECTURE.md). Экосистема преднамеренно остаётся экспериментальной учебной моделью, а не биологическим симулятором с доказанной точностью.

## Приёмка Windows — открытые задачи

- [#5](https://github.com/Onmaynec/Life/issues/5): реальное поведение на Windows 10/11 при 1366×768 и 1920×1080, DPI 100/125/150, русских надписях. Автоматический тест компоновки есть, но реальная приёмка не выполнена.
- [#6](https://github.com/Onmaynec/Life/issues/6): уже реализованы упаковка и запуск EXE в CI; требуется проверка на чистых Windows 10/11 с сохранениями и экспортом.
- [#7](https://github.com/Onmaynec/Life/issues/7): нативный тёмный заголовок с fallback; проверить пользовательские Win10/11 и режимы системной темы.

## После 1.0.1

1. Профилировать сценарии на больших мирах, ограничить память и дать выбор способа вычислений без потери воспроизводимости.
2. Сохранять шаблоны пользовательских интервенций и сравнивать более двух вариантов при равных условиях и нескольких повторах.
3. Добавить удобный браузер исследовательских архивов с просмотром манифеста, отчёта и открытием выбранной ветки.
4. Развить биомные границы, экологические ниши и генетику с чётко документированными допущениями.
5. Провести доступность интерфейса: масштабирование текста, экранный диктор, управление только с клавиатуры, контрастность в темах.

Новые Issues создаются для конкретной задачи с критериями и шагами проверки. Завершение задачи не приписывается версии до проверки всех критериев.
