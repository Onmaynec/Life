| Issue | Изменение | Подтверждение | Ограничение |
| --- | --- | --- | --- |
| #4 | Убраны лишние обращения к размерам мира и повторное построение квадратов видимости, ускорено ограничение генов | Фиксированные seed, тесты, замеры в `tools/benchmark.py`, хеши одинаковы | Скорость зависит от CPU и плотности популяции |
| #5 | Адаптивное раскрытие панелей, компактная верхняя строка, прокручиваемый диалог создания мира, горячие клавиши скорости | Тесты точек переключения, запуск в Xvfb на 780×490, 900×640 и 1366×768 | Требуется ручное подтверждение Windows 10/11 при 100–150% и скриншоты |
| #6 | Windows CI собирает каталог `Life.exe` через PyInstaller, запускает встроенный smoke-тест и сохраняет artifact | Итог конкретного GitHub Actions run | Нужна проверка EXE на чистых Windows 10 и 11 перед публикацией в Releases |
| #7 | DWM с поддержкой 20/19, 35/36 и безопасным откатом к системному заголовку | Проверка парсинга цветов, кроссплатформенного fallback | Требуется ручная проверка тёмной рамки, Alt+Tab, DPI и системных тем Windows 10/11 |
| #8 | Агрегация `mean/max/sum`, детализация 17–65 ячеек, шкала с единицами, пропуск повторных построений по поколению | Проверки математических значений и сохранения исходного поля | Отрисовка большого числа 3D-столбцов остаётся требовательной к CPU |
| #9 | Строгая загрузка JSON, проверка версии/индексов/чисел, журнал открытых серий, общий график и CSV с источником | Регрессионные тесты включая повреждённые и частичные отчёты | Отдельные записи могут отсутствовать — интерполяции нет |

## Что проверить вручную на Windows

1. Windows 10 (22H2) и Windows 11: разрешения 1366×768 и 1920×1080, масштаб интерфейса 100%, 125%, 150%. Приложить скриншоты всего окна и диалога создания мира.
2. На обоих ОС переключить светлую и тёмную системные темы, сменить оформление Life, проверить текст заголовка, кнопки свернуть/развернуть/закрыть, Alt+Tab, максимизацию и перенос между мониторами с разным DPI.
3. На чистых системах распаковать Windows artifact, запустить `Life.exe` без Python, проверить классический режим, экосистему, сохранение `.lifelab`, открытие RLE, экспорт PNG/CSV, отдельное 3D-окно и запись `preferences.json` в `%APPDATA%\\Life`.
4. После проверки автономного запуска можно добавить автоматическую публикацию EXE в GitHub Releases. До этого релиз включает исходники; Windows artifact — кандидат, а не проверенный пользовательский дистрибутив.

Команда тестов: `python -m unittest discover -s tests -v`.
