# Аудит задач и веток перед Life v1.0.0

На дату подготовки версии **14 ноября 2026 года** у репозитория одна ветка: `main`. Лишние ветки не обнаружены; удалять и сливать нечего. В этой версии изменения вносятся непосредственно в `main` одним проверенным коммитом.

К моменту аудита открыты три задачи:

- [#5 — небольшие экраны и High-DPI](https://github.com/Onmaynec/Life/issues/5). В версии 1.0.0 добавлен расчёт ширины с учётом DPI, компактная верхняя панель и проверка виджетов через UI smoke. Для закрытия исходной задачи нужен тест на Windows 10/11 при 1366×768 и 1920×1080 с масштабом 100%, 125%, 150% и скриншотами.
- [#6 — автономная Windows-сборка](https://github.com/Onmaynec/Life/issues/6). Workflow собирает пакет с `Life.exe`, запускает engine/UI smoke и публикует ZIP в Releases только после проверки. Работа в Windows Server 2022 CI не доказывает работу на чистых Windows 10/11; для закрытия нужен отдельный пользовательский приёмочный тест.
- [#7 — тёмный заголовок окна](https://github.com/Onmaynec/Life/issues/7). Реализована безопасная попытка применения DWM и fallback. Необходимы реальные Windows 10/11, светлая и тёмная системные темы, Alt+Tab, минимизация, максимизация и DPI 100–200%.

**Правило завершения:** задача закрывается только тогда, когда её критерии приёмки выполнены. Нельзя считать ручной тест на Windows 10/11 успешным лишь по Linux/Xvfb или Windows Server runner. Задачи не дублируются; ссылки на изменения и отчёты добавляются в исходные Issues.
