# Лаборатория сценариев — v1.0.0

В **Scenario Studio** один и тот же мир одновременно развивается двумя способами: контрольным (без внешнего изменения) и экспериментальным (с заданными воздействиями). Метод полезен для изучения **внутреннего поведения модели**, а не прогнозирования природных процессов.

## Подготовка

1. Включить режим «Экосистема», создать или загрузить исходный мир. Открыть окно «СЦЕНАРИИ» в верхней панели (`Ctrl+Shift+E`).
2. Выбрать шаблон или составить последовательность собственных воздействий. Если событие меняет дождь, температуру, болезни, пожары или перенос влаги, предварительно включить расширенную модель экологии в основной панели «Среда».
3. Выбрать длительность от 1 до 1000 поколений и интервал измерения. На коротком опыте заранее убрать из шаблона события, запланированные после его окончания.
4. Запустить процесс. В любой момент можно поставить расчёт на паузу, продолжить или остановить. В основной игре мир остаётся на прежнем поколении, пока пользователь не запустит его отдельно.

## Воздействия и их интерпретация

| Вмешательство | Что меняется | Ограничение |
| --- | --- | --- |
| Влажность | Прибавление числа ко всем клеткам `moisture` | Сатурация 0–100 |
| Минералы | Прибавление числа ко всем клеткам `nutrients` | Сатурация 0–100 |
| Токсины | Прибавление числа ко всем клеткам `toxins` | Сатурация 0–100; не всякая комбинация параметров среды даёт биологический эффект |
| Осадки | `ecology.rain` | 0–1, только с включённой расширенной экологией |
| Тепло | `ecology.heat` | 0–1, только с включённой расширенной экологией |
| Болезни | `ecology.disease` | 0 или 1, только с включённой расширенной экологией |
| Пожары | `ecology.wildfire` | 0 или 1, только с включённой расширенной экологией |
| Перенос влаги | `ecology.moisture_flow` | 0–1, только с включённой расширенной экологией |

Шаблоны: **Засуха, Ливни, Истощение почвы, Восстановление почвы, Загрязнение, Очистка**. От одного до 32 вмешательств за опыт. События с одинаковой отметкой выполняются в том порядке, в котором они находятся в плане. Метка `0` означает **перед первым шагом**, `30` — после 30 выполненных поколений, перед 31-м.

## Методика сравнения

При создании опыта выполняются три копии исходного мира: неизменяемая точка старта, контрольная и экспериментальная ветви. В каждой копии фиксируются начальные матрицы, родословные, ресурсы и состояние RNG. Далее программа обновляет сначала контрольную, затем экспериментальную ветку, не делая дополнительных случайных выборов при наложении воздействия.

Первая запись относится к стартовому поколению. Последняя запись всегда относится к последнему выполненному шагу, даже если он не совпадает с интервалом измерений. Если животных нет, средняя энергия обозначается отсутствующим значением, а не фиктивным нулём. Расхождение двух ветвей **возможно не только из-за прямого изменения ресурса**, но и из-за того, что после изменения условий последовательности событий могут по-разному использовать RNG.

## Экспорт и проверка

Кнопки в правой части окна:

- **CSV:** по две записи на каждый момент наблюдения, с колонкой `branch = control | scenario` и показателями видов, минералов, влажности, токсинов, энергии, рождений и смертей.
- **JSON:** план, все применённые события, фактически выполненные поколения, измерения и итоговая разница.
- **Архив опыта:** ZIP с `initial.lifelab`, `control.lifelab`, `scenario.lifelab`, `measurements.csv`, `report.json` и `manifest.json` (SHA-256 для каждого файла, кроме самого манифеста).

Проверка целостности ZIP:

```bash
python -m life_lab.scenarios путь/к/опыту.zip
```

После распаковки файлы `.lifelab` можно открыть как обычные миры, в том числе продолжить от итоговых ветвей. Процедура проверки читает только ожидаемые имена файлов, ограничивает размеры и сравнивает хеши; она **не извлекает пути из архива на диск**.

**Ограничения:** это парное сравнение, а не статистическая оценка с множеством независимых повторов. Для изучения разброса используйте **Experiment Lab**. Пакет не содержит исполняемого кода, не отправляет данные на сервер и не воспроизводит окружающую природу.
