# Целостность данных и границы доверия

Life не запускает исполняемый код из файлов мира или архивов экспериментов. Сохранения `.lifelab` читаются как NPZ с `allow_pickle=False`. Перед распаковкой проверяются допустимый размер исходного файла (256 МиБ), число ZIP-элементов (не более 48), максимальный размер отдельного распакованного элемента (256 МиБ), суммарный размер (512 МиБ) и отсутствие дублирующихся имён. Затем проверяются размерность матриц, типы полей, генетика, история и поколение.

Полностью защититься от всех видов сбоев файловой системы и злоумышленных файлов только указанными ограничениями нельзя. Не открывайте сохранения неизвестного происхождения в привилегированном контексте. Для Windows-сборки используется отдельная локальная папка, пользовательские данные и контрольные точки не хранятся внутри установленной программы.

При сохранении `.lifelab` сначала записывается временный файл в ту же директорию с `fsync`. Только после успешной записи он атомарно заменяет целевой путь (в рамках гарантий ОС/файловой системы). Это не заменяет резервное копирование важных исследований.

ZIP-архив сценария содержит только заранее заданные файлы: стартовый, контрольный и экспериментальный миры, CSV, JSON-отчёт и SHA-256 манифест. Команда `python -m life_lab.scenarios файл.zip` проверяет ожидаемый список, размер и хеши каждого элемента. Не пытается автоматически запускать или извлекать произвольные файлы из ZIP.

Программа работает локально. В пакет не включены облачные зависимости, рекламные SDK или телеметрия. Ошибки можно оформить в [Issues](https://github.com/Onmaynec/Life/issues) с обезличенным описанием и шагами воспроизведения; приватные сохранения публиковать не требуется.
