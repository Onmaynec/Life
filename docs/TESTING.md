# Проверка интерфейса Life

## Автоматические тесты

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Тесты не открывают графическое окно: они проверяют правила симуляции, сохранения, графики данных, палитры, все режимы отрисовки и настройки приложения.

## Проверка на компьютере

1. Запустить `python main.py` или `START_WINDOWS.bat`. Убедиться, что все три области окна видимы, переключение режимов и кнопки запуска работают.
2. Включить экосистему. Менять «Аврору», «Биосферу», «Ультрафиолет» и три стиля клеток; численность и поколение при этом не должны меняться.
3. Провести несколько шагов. Сравнить графики с цифрами в статистике, выбрать клетку и проверить её признаки в инспекторе.
4. Увеличить поле колесом, переместить его средней кнопкой мыши и через мини-карту; проверить «Вписать».
5. Открыть окно нового мира, создать мир с известным seed, сохранить его, открыть повторно. Проверить экспорт PNG и CSV.
6. Изменить палитру, стиль и скорость, закрыть приложение и открыть снова: настройки должны сохраниться.
7. Проверить минимальный размер окна и масштабирование ОС. На небольшом разрешении панели прокручиваются колесом мыши.

Полная проверка реального Windows-дисплея, разных DPI и упаковки в EXE остаётся отдельной задачей; запуск в виртуальном X-сервере не заменяет её.
