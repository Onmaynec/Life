# Родословные и эволюция в Life

В v0.7.0 добавлен учёт происхождения животных. Это **регистрация реальных событий симуляции**, а не реконструкция родства по похожим генам. У растений происхождение пока не фиксируется; классический клеточный автомат работает без этой системы.

## Как пользоваться

1. Перейдите в режим «Экосистема», создайте мир и запустите несколько поколений.
2. Откройте вкладку **«Родословная»** справа. Здесь показываются количество живых животных, активные родовые линии, максимальное и среднее колено, распределение глубины родословных и восемь крупнейших линий.
3. Наведите курсор на животное и нажмите **Ctrl+ЛКМ**. Выбранное животное откроется на вкладке со своим ID, координатой (если живо), годом рождения, геномом при рождении, числом прямых потомков, основателем и цепочкой предков.
4. Нажмите «Экспорт родословных CSV», чтобы получить реестр животных для анализа вне приложения.
5. Для пространственной картины поколений выберите **«Глубина родословной»** во вкладке «3D» и откройте 3D-студию. Значение 0 обозначает основателя; большее число — более далёкое колено. Пустые клетки и растения имеют значение 0.

Дополнительно доступны показатели «Активные родовые линии», «Макс. колено», «Среднее колено», «Записи родословной» на вкладке «Анализ» и в её CSV-экспорте.

## Какие данные хранятся

| Поле | Смысл |
|---|---|
| `id` | Уникальный ID животного в пределах одного мира |
| `species` | 2 — травоядное, 3 — хищник |
| `parent` | ID родителя; 0 у основателя |
| `founder` | ID основателя исходной линии |
| `depth` | Количество родительских связей до основателя |
| `born` | Поколение появления |
| `died`, `cause` | Поколение и причина гибели; пустое `died` у живого животного |
| `offspring` | Число непосредственных потомков за всё время жизни |
| `mutated` | Отмечено ли изменение генов при рождении по действующему порогу |
| `genome` | Метаболизм, зрение и плодовитость при рождении |

**Живое животное остаётся тем же** при обычном движении и миграции. При появлении потомка создаётся новый ID и привязывается к ID родителя. При поедании, голоде или гибели из-за среды запись остаётся в родословной с причиной смерти. Рисование кистью создаёт нового основателя; стирание фиксирует смерть от редактирования. Массовое случайное заполнение начинает новый реестр.

Изменения записываются без дополнительных вызовов генератора случайных чисел, поэтому одинаковый seed сохраняет воспроизводимость симуляции при одинаковых условиях.

## Сохранения и старые миры

Формат `.lifelab` повышен до **версии 5**. ID каждого живого животного хранятся в массиве `animal_ids`, записи о предках — в `metadata.lineage`. Проверяются соответствие ID и вида клетки, отсутствие повторяющихся живых ID и корректность записей. Сохранения версий 1–4 открываются. Поскольку в них происхождение не записывалось, **каждое животное на момент загрузки становится основателем собственной линии**; прошлую родословную восстановить невозможно. Новый формат после этого сохраняется обычным способом.

Исследовательский журнал из v0.5–v0.6 при загрузке сохраняет прежние измерения. Новые поля родословной для старых поколений остаются пустыми — данные не выдумываются.

## Ограничения модели

- Размножение пока **бесполое**: у потомка один родитель. Появление новых биологических видов здесь не моделируется.
- Изменяемые гены остаются тремя: метаболизм, зрение и плодовитость. Они наследуются с небольшим шумом и ограничены исходными допустимыми диапазонами.
- ID уникален **в пределах мира**, а не между двумя независимыми мирами или сериями экспериментов.
- После превышения 52 500 записей реестр удаляет старые записи умерших животных. Сначала удаляются записи, не входящие в цепочки живых особей; если этого недостаточно, очистка может оборвать старую часть цепочки предков. Записи живых ID никогда не удаляются. Поэтому при популяции выше лимита размер реестра не может быть меньше числа живых животных. Число удалённых записей отображается в панели; CSV включает только сохранившиеся записи.
- Глубина родословной и число линий описывают **модельную историю**, а не генетическое разнообразие по ДНК и не научные оценки приспособленности.
