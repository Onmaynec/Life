# Участие в разработке

Если нашли ошибку, откройте Issue с кратким описанием, шагами воспроизведения, ожидаемым и фактическим результатом. Для проблем с сохранениями укажите версию Life и режим симуляции. Файлы сохранений могут содержать состояние эксперимента, поэтому публикуйте только те, которыми готовы поделиться.

Перед изменением логики запустите `python -m unittest discover -s tests -v`. Для нового поведения желательно добавить проверку с фиксированным seed: так легче увидеть, что именно изменилось.

В документации и описаниях изменений пишите, что уже работает, а не то, что только планируется. Для крупных изменений лучше сначала открыть Issue, чтобы обсудить механику и совместимость сохранений.
